# MEMESTACK

**Stack the funny.**

Mobile-first meme community prototype.

## V1 included
- English / French interface
- Mobile-first navigation
- Meme upload from phone gallery
- Image/GIF preview
- Local prototype publishing
- Meme feed
- Battle voting
- Stack Points
- Leaderboard
- Creator profile

## Current architecture
This first version is intentionally a static HTML prototype so it can be previewed quickly.

### Next steps
1. Deploy on Vercel
2. Add authentication
3. Add cloud image storage
4. Add database-backed memes and votes
5. Add real battle matchmaking
6. Add creator rewards and sponsored prize battles
